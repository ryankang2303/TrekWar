# Trekwar

Turn your everyday steps and miles into progress in real-world distance races against your friends (or the world). See [MVP.md](./MVP.md) for the full plan.

## Run

```
npx expo start --go
```

Scan the QR code with Expo Go on a physical device. No dev client needed yet.

## SDK

Currently on Expo SDK 54. Before bumping the `expo` package, re-check which
SDK version Expo Go on the Apple App Store actually supports — it commonly
lags behind the latest `expo` npm release.
